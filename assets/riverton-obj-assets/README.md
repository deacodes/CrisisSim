# Riverton OBJ asset pack

Original low-poly assets created for CrisisSim's synthetic emergency-response city. This collection is a consistent, browser-friendly city kit.

## Models
- apartment-building.obj — courtyard apartment with balconies and roof plant
- office-tower.obj — civic office tower with podium and lobby
- row-house.obj — three connected townhouses
- hospital.obj — emergency wing, helipad, and red medical cross
- emergency-shelter.obj — community shelter with solar panels
- bridge.obj — evacuation bridge with towers, piers, and rails
- rescue-boat.obj — purpose-built flood rescue boat
- ambulance.obj — advanced life-support ambulance with correctly oriented wheel axles
- tree.obj — street tree
- flood-barrier.obj — modular flood barrier
- emergency-park.obj — assembly park with benches and signage

All OBJ files reference `riverton.mtl`. Keep that material file beside the OBJ files during import.

## Import
In Blender, use **File → Import → Wavefront (.obj)**. For Three.js, load the files with `OBJLoader` and `MTLLoader`, or convert selected models to GLB in Blender for faster web delivery.
