# Original frontend integration

All twelve HTML pages retain their incumbent navigation, cards, columns and
styling. `js/app.js` binds their named data slots to the backend. The API serves
these same files unchanged. No server-side replacement of the main interface
occurs. The old fixture scripts and alternate live dashboard were removed;
their previous versions remain in Git history.

## Sources of truth

- Scenario library, wizard, duplication, editing and archive: `/api/v1/scenarios`.
- Run selection, execution, pause, resume, cancel and retry: `/api/v1/runs`.
- Metrics, timeline, replay and maps: immutable snapshot/field artifacts.
- Terrain, roads and facilities: city/mesh artifacts generated by that run.
- Comparisons, NSGA-II, Monte Carlo and Morris: `/api/v1/experiments`.
- Report exports: server-generated JSON/CSV; print uses the selected snapshot.
- Settings: local appearance/layer preferences. Scenario import is validated
  as a batch and committed in one database transaction.

Charts plot recorded data only. Neighborhood gap is expressed as percentage
points; mean evacuation time includes completed residents only. Not-yet-safe
includes all unfinished states, not only stranded residents. The all-residents
state count is independent of the display sample.

Unsupported claims were removed: composite equity scores, census/USGS
calibration, mortality/survival, forecast overlays, Sobol indices, clinical ICU
loads, fabricated baseline improvements and automatic policy approval.

## Connection lifecycle

Same-origin API is preferred. Local editor previews can fall back to port 8010.
Only explicitly allowlisted loopback origins can write or open streams.
External origins are rejected; this remains a local single-user application,
not a publicly authenticated service.

Simulation pages observe run records. Policy Lab and Uncertainty instead
observe experiment records, with separate saved experiment selections.
WebSocket messages signal changes; HTTP fetches authoritative versioned records.
Polling continues during socket failures. Reconnect delay is bounded and
terminal records close the subscription. Page navigation stops subscriptions
and disposes map renderers. Run generation/request counters reject stale frame
responses. A missing API never activates a mock simulator.

## Verification

The backend tests cover local-origin CORS, experiment WebSocket notifications,
atomic import validation, original-page serving, numerical metrics, lifecycle,
determinism and the prior audit regressions.

The opt-in browser test creates a scenario through the original wizard, runs
it, compares UI metrics to backend artifacts, uses OBJ/2D maps and replay,
creates policy and uncertainty experiments with WebSockets unavailable, visits
all pages and checks narrow-view overflow. It uses Playwright's isolated
browser; never set `PLAYWRIGHT_CHROME` to the user's installed browser.

The model is still synthetic and uncalibrated. Integration tests do not prove
real-world forecast accuracy or production readiness. Old results retain their
original provenance and may lack newly added demographic/depth summaries;
missing measures display as unavailable rather than being invented.
